# AGENTS.md — Tuto

## What is this

Tuto is a desktop app for learning technical concepts through an AI tutor. A lesson is a feed of short, readable cards generated by Claude — with syntax-highlighted code, Mermaid diagrams, a per-concept Practice tab of fill-in-the-blank exercises, and a structured Notes document that builds up as you go. A card that has one line worth keeping carries a **takeaway**, shown under it and filed into the notes (`docs/system/takeaways.md`). It is a personal tool: instead of calling an API, it spawns the local `claude` CLI (Claude Code headless mode) as its AI backend. The product plan and design rationale live in `docs/app-plan.md`.

A lesson comes in one of two **modes**: a *topic* lesson is taught from what the model knows; a *codebase* lesson is taught from a project on this machine, which the tutor reads with read-only tools. Everything mode-specific lives in `src/bun/lesson-modes.ts` and `prompts/modes/` — see `docs/system/lesson-modes.md` before adding a third, and before changing anything that affects what a turn costs.

## Stack

- Shell: Electrobun — a Bun main process plus the OS's native WebView.
- UI: React + TypeScript, bundled by Vite; the WebView loads the build from `dist/`.
- Styling: Tailwind CSS v4 with shadcn/ui components (Base UI primitives, Hugeicons, Shiki for code, mermaid.js for diagrams).
- AI backend: the `claude` CLI, spawned per turn from the Bun process. It must be installed and authenticated on the machine.
- Persistence: plain files under the OS app-data dir — one folder per lesson holding `lesson.json`, `notes.md`, and `notes.json`. No database.
- Lint/format: Biome.
- Package manager: pnpm (required). Bun is the app runtime, not the dependency manager. Exact-version pinning is enforced by `savePrefix: ""` in `pnpm-workspace.yaml`.

## Directory index

| Path | What's there |
|------|-------------|
| `src/bun/` | Bun main process: window + RPC (`index.ts`), the `claude -p` wrappers (`claude.ts`), lesson modes (`lesson-modes.ts`), project picking (`project.ts`), the project map a codebase lesson opens with (`repo-map.ts`), lesson store (`store.ts`), notes document (`notes.ts`), data paths (`paths.ts`). |
| `src/mainview/` | React WebView UI. `App.tsx` holds the app; `components/` has the cards, tabs, practice, notes, explain, project picker, settings, and the margin beside the feed (`margin-layer.tsx`, with `sticky-notes.tsx` and `question-threads.tsx` in it); `lib/` has the RPC bridge and demo fixtures. |
| `src/shared/` | `types.ts` — the typed RPC schema shared between the Bun process and the WebView, and `LessonConfig`. |
| `prompts/` | System prompts, imported into the Bun process as text: the core `tutor.md`, one section per lesson mode in `modes/`, and the side-calls (`discuss.md`, `exercise-check.md`, `exercise-regen.md`, `explain.md`, `mermaid-fix.md`). |
| `scripts/` | Headless test scripts. `tutor-smoke.ts`, `codebase-smoke.ts`, and `exercise-smoke.ts` call the real model; `card-parse-test.ts` is token-free. |
| `docs/` | Durable project context (plus `app-plan.md`). Sub-folder layout below. |

```
docs/
├── system/         ← what the code does today (updated as code changes)
├── architecture/   ← what the system must do (updated when rules change)
├── adr/            ← architecture decisions (immutable once shipped)
├── reference/      ← long-form rationale (append-only)
└── working-notes/  ← research; NOT authoritative — rules live in architecture/ + adr/
```

## Commands

The app is a desktop binary, not a web server. All commands run through pnpm.

| Command | What it does |
|---------|-------------|
| `pnpm start` | Build the WebView and launch the desktop app from bundled views. |
| `pnpm dev` | Same, but with Vite HMR. HMR is opt-in via `TUTO_HMR=1`; auto-detecting a running dev server is intentionally disabled, so only `pnpm dev` uses it. |
| `pnpm smoke` | Run the tutor loop against the real `claude` model end to end. Spends tokens. |
| `pnpm smoke:codebase <path> [question]` | Same, for a codebase lesson: checks the tutor reads the project and cites it. Spends tokens. |
| `pnpm smoke:exercise` | Reject a bad exercise and check the replacement blanks real code. Spends tokens. |
| `pnpm smoke:prerequisite` | Check the "start one step back" offer fires where it should and stays quiet where it shouldn't. Spends tokens. |
| `pnpm run test:parse` | Card-parse regression test over malformed replies. Token-free. |
| `pnpm typecheck` | `tsc --noEmit`. |
| `pnpm lint` / `pnpm format` | Biome check / format. |
